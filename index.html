Architecture

Engineered without compromises.

Everything you need from a modern client mod, with none of the telemetry you didn't ask for.

01 / LOCAL FIRST

Cloud telemetry completely excised.

All tracking endpoints, remote sync hooks, and cloud storage tabs have been deleted from the codebase. Your settings, plugins, and custom styles remain strictly on your hardware.

02 / STANDALONE

100% Portable .exe

A single executable built with native C# WPF. No Node.js runtime, Git binaries, or command prompt required.

03 / ECOSYSTEM

Extensive Plugin Suite

Comes packed with hundreds of vetted plugins: message utilities, notification tweaks, themes, visualizers, and performance boosters.

04 / REPO INTEGRATED

Native GitHub Changelog & Updater

Directly checks for commit updates from domdoesntdodrip/dimcord using GitHub's REST API. Inspect new commits, read changelogs, and keep your installation current in real time.

05 / BROWSER READY

Unpacked Web Extension

Prefer Discord in Chrome or Firefox? Load Dimcord directly as a Manifest V3 extension with full feature parity.

06 / PERMANENT INJECTION

Decoupled AppData Storage

Injects cleanly into %AppData%\Dimcord\dist\desktop. You can delete or move installer files anytime without breaking your Discord installation.
